## Getting Started

### Requirements

- [Python 3](https://www.python.org/downloads/) (3.8 or newer recommended)

### Clone the repository

```bash
git clone https://github.com/BenyaminTo/Exercises-from-the-book-on-programming-in-Python.git
cd Exercises-from-the-book-on-programming-in-Python
```

### Run a solution

```bash
python "Season 1/<file_name>.py"
```

Replace `<file_name>` with the exercise file you want to run. Folder names contain spaces, so keep the quotes around the path.

## Usage Tips

- Try each exercise on your own first, then compare your solution with the one here.
- There is usually more than one correct way to solve a problem, so differences are expected.
- Read the code, then modify it and experiment to see how the behavior changes.
